# Setup

1. Create a **public** GitHub repository named `tharun2509`.
2. Copy all files from this package into it.
3. Commit and push.
4. Open **Actions → Generate profile graphics → Run workflow** once.
5. Open your profile: https://github.com/tharun2509

The workflow refreshes the live SVG statistics once per day using the repository's built-in `GITHUB_TOKEN`.

The `ascii.svg` portrait was generated from the photo you provided. The original photo is **not included**.
